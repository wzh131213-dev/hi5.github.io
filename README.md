# 2.5D 异界冒险者 (Isometric Dungeon ARPG)

基于 **Three.js** 和 **Web Audio API** 开发的高性能 2.5D 等轴视角（Isometric）地牢 ARPG 网页游戏。

## 🎮 游戏特色

- **2.5D 等轴 3D 视角**：使用 Three.js 正交相机（OrthographicCamera）打造经典 2.5D ARPG 视角，支持动态光影与柔和阴影。
- **丰富技能与战斗**：
  - 🗡️ **普通攻击**：弧形斩击（J / 左键）
  - ⚡ **影之冲刺**：快速位移与无敌帧（K / Space）
  - 🔥 **烈焰风暴**：大范围 AOE 魔法火环（L / 1）
  - 💚 **圣光治愈**：恢复生命值（H / 2）
- **多样化怪物 AI**：
  - 史莱姆（Slime）
  - 骷髅战士（Skeleton Warrior）
  - 深渊巨魔 Boss（Boss Demon）
- **关卡与肉鸽强化**：
  - 波次刷怪机制与关卡传送门
  - 升级三选一肉鸽强化（攻击提升、生命上限提升、疾风步）
  - 宝箱掉落与金币收集
- **完整 HUD 与音效**：
  - 实时小地图 Radar
  - Web Audio API 原生合成音效与地牢背景音乐
  - 浮动伤害与经验数值提示

## 🕹️ 操作指南

- **WASD / 方向键**：控制角色 8 方向移动
- **鼠标**：指向瞄准
- **J / 鼠标左键**：普通攻击
- **K / 空格键**：影之冲刺
- **L / 数字键 1**：烈焰风暴
- **H / 数字键 2**：圣光治愈
- **P / ESC**：暂停游戏
